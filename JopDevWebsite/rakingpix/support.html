RakingPix Support

Need help with RakingPix? Start with the common topics below.

Need to install or reinstall the extension? Get RakingPix from the Chrome Web Store.

Scanning a webpage

Open the RakingPix side panel on the webpage you want to scan, then choose Scan Page. If the results look incomplete, wait for the page to finish loading and scan it again.

Filtering results

Use the available filters to narrow the results. Min Width and Min Height are useful for excluding small icons, thumbnails, and decorative images. Clear or reduce those values if an image you expect is missing.

Selecting and downloading images

Choose individual images, use Select All for the current results, or use Clear All to start over. When your selection is ready, choose Download Selected. Chrome may ask you to confirm downloads or allow multiple files.

File names and folders

Use the naming options to customize filenames and automatic numbering. You can also organize files into folders and subfolders. Check the live filename and path previews before downloading to catch unexpected names or folder paths.

Settings and help

Review RakingPix settings if you want to change saved preferences. The tutorials and in-extension help explain the current side-panel workflow.

Permissions

RakingPix needs access to the active webpage to scan for images, download access to save the files you select, and extension storage for settings and workflow state. If scanning or downloading is blocked, check the extension's Chrome permissions and the site's own access restrictions.

Something not working?

Reload the webpage, reopen the side panel, and try Scan Page again. Check that Chrome allows downloads and that the source image is still available. Some protected, temporary, embedded, or cross-origin images may not be downloadable. If the problem continues, include what you tried, what happened instead, the webpage URL if it is safe to share, and your Chrome and RakingPix versions.
