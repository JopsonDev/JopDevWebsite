INSTALL THE WEB APP

Athlete OS lives on your home screen.

This is a progressive web app (PWA), not a native App Store download. There is no IPA or APK file.



Install on iPhone

  1. Open Athlete OS in Safari.
  2. Tap Share.
  3. Choose Add to Home Screen.
  4. Turn on Open as Web App.
  5. Tap Add.

In short: Open in Safari > Share > Add to Home Screen > Open as Web App > Add.

Install on Android

  1. Open Athlete OS in a supported browser such as Chrome.
  2. Tap Install app when offered.
  3. If it is not shown, open the browser menu and choose Install app or Add to Home screen.

The install prompt appears only in supported browsers after the app opens.

Local-first data

Your records belong to you.

Athlete OS starts with no personal logs. Browser updates do not erase IndexedDB records under normal storage behavior. Complete JSON backup and validated restore are built in for portability and recovery.
